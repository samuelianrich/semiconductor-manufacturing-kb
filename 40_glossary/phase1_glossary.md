# Phase 1 glossary

Reviewed by the repository author, 2026-09-16. Definitions are concise navigation aids; assumptions, illustrations and source locators live in the linked articles.

## Feedstock and refining

Canonical starting explanation: [Quartz, silica and qualified furnace feedstock](../01_raw_materials/quartz_and_feedstocks.md). Related sequence: [Phase 1 reading path](../LEARNING_PATHS.md#phase-1-reading-path). Sources: [USGS-SILICON-001](../42_references/bibliography.md#usgs-silicon-001), [NTNU-SMELTING-001](../42_references/bibliography.md#ntnu-smelting-001), [WACKER-POLY-001](../42_references/bibliography.md#wacker-poly-001), [HSC-POLY-001](../42_references/bibliography.md#hsc-poly-001).

<a id="silicon"></a>
**Silicon.** Chemical element Si; the semiconductor host discussed here.

<a id="silica"></a>
**Silica.** Silicon dioxide, SiO₂; a compound, not elemental silicon.

<a id="quartz"></a>
**Quartz.** A crystalline form of silica.

<a id="quartzite"></a>
**Quartzite.** A quartz-rich rock; deposit composition and texture determine suitability.

<a id="beneficiation"></a>
**Beneficiation.** Processing that improves a mineral feed by removing unwanted material or separating useful fractions.

<a id="grade"></a>
**Grade.** Proportion of a specified constituent in a feed or product; state whether mass or atomic fraction.

<a id="recovery"></a>
**Recovery.** Fraction of the specified input constituent retained in the chosen output.

<a id="reductant"></a>
**Reductant.** A reactant that helps remove oxygen in the furnace chemistry; carbon-bearing feeds serve this role.

<a id="metallurgical-grade-silicon"></a>
**Metallurgical-grade silicon.** Furnace-produced silicon requiring additional purification for the electronic-material route.

<a id="chlorosilane"></a>
**Chlorosilane.** A silicon compound containing chlorine; volatile chemistry enables separation before redeposition.

<a id="trichlorosilane"></a>
**Trichlorosilane.** HSiCl₃, often abbreviated TCS; a feed chemical in the representative polysilicon route.

<a id="distillation"></a>
**Distillation.** Separation using differences in vapor/liquid partitioning.

<a id="siemens-process"></a>
**Siemens process.** Polysilicon deposition on heated silicon surfaces from purified precursor gas.

<a id="fluidized-bed"></a>
**Fluidized bed.** A reactor bed of particles suspended by gas flow; deposition can grow silicon granules.

<a id="polysilicon"></a>
**Polysilicon.** Silicon containing many crystal grains; chemical purity does not make it a single crystal.

<a id="contamination"></a>
**Contamination.** Unwanted material introduced into or onto the product, judged against its use and specification.

## Crystal and wafer

Canonical starting explanation: [Single-crystal growth: giving silicon a continuous lattice](../03_crystal_growth/crystal_growth.md). Related sequence: [Phase 1 reading path](../LEARNING_PATHS.md#phase-1-reading-path). Sources: [SUMCO-WAFER-001](../42_references/bibliography.md#sumco-wafer-001), [KIEL-GROWTH-001](../42_references/bibliography.md#kiel-growth-001), [KIEL-SEGREGATION-001](../42_references/bibliography.md#kiel-segregation-001), [SEMI-TERMS-001](../42_references/bibliography.md#semi-terms-001), [SEMI-WAFER-001](../42_references/bibliography.md#semi-wafer-001).

<a id="crystal-lattice"></a>
**Crystal lattice.** An ordered repeating arrangement used to describe a crystal.

<a id="single-crystal"></a>
**Single crystal.** Material with a continuous crystal orientation rather than multiple differently oriented grains.

<a id="seed"></a>
**Seed.** An oriented crystal that starts controlled crystal growth.

<a id="boule"></a>
**Boule.** A grown crystal body subsequently prepared for wafer production.

<a id="czochralski-growth"></a>
**Czochralski growth.** Seeded pulling from a contained melt; abbreviated CZ.

<a id="float-zone-growth"></a>
**Float-zone growth.** Growth using a traveling molten zone without a contacting melt crucible; abbreviated FZ.

<a id="segregation-coefficient"></a>
**Segregation coefficient.** The interface solid-to-liquid impurity concentration ratio under specified conditions.

<a id="crystal-orientation"></a>
**Crystal orientation.** The lattice direction or plane relative to the wafer or growth axis; different from a wafer position in a carrier.

<a id="vacancy"></a>
**Vacancy.** A missing atom at a normally occupied lattice site; distinct from a mobile electronic hole.

<a id="interstitial"></a>
**Interstitial.** An atom occupying a position between normal lattice sites.

<a id="dislocation"></a>
**Dislocation.** A line defect in the crystal arrangement.

<a id="kerf"></a>
**Kerf.** Material removed by the slicing cut; it contributes to mass loss.

<a id="lapping"></a>
**Lapping.** Mechanical removal used to improve wafer geometry and remove cutting-related damage.

<a id="polishing"></a>
**Polishing.** Surface finishing through controlled chemical and mechanical removal.

<a id="total-thickness-variation"></a>
**Total thickness variation.** Maximum minus minimum thickness over a specified measurement region; abbreviated TTV.

<a id="bow"></a>
**Bow.** Signed center displacement of the wafer median surface from a specified reference plane, under defined support conditions.

<a id="warp"></a>
**Warp.** Difference between maximum and minimum median-surface deviation from a specified reference plane; distinct from thickness variation.

<a id="surface-roughness"></a>
**Surface roughness.** Small-scale topography quantified using a specified statistic, area and spatial filtering.

<a id="edge-exclusion"></a>
**Edge exclusion.** A stated peripheral region excluded from a particular measurement or usable-area definition.

<a id="acceptance"></a>
**Acceptance.** Disposition against specified measurements and limits; it is not proof of zero defects.

<a id="epitaxy"></a>
**Epitaxy.** Growth of a crystalline layer with an orientation relationship to the underlying crystal.

<a id="silicon-on-insulator"></a>
**Silicon on insulator.** A silicon device layer separated from a supporting substrate by an insulating layer; abbreviated SOI.

## Carriers and junctions

Canonical starting explanation: [Bonding, energy bands, electrons and holes](../05_semiconductor_physics/bonding_bands_and_carriers.md). Related sequence: [Phase 1 reading path](../LEARNING_PATHS.md#phase-1-reading-path). Sources: [HU-PHYSICS-001](../42_references/bibliography.md#hu-physics-001), [HU-TRANSPORT-001](../42_references/bibliography.md#hu-transport-001), [HU-PN-001](../42_references/bibliography.md#hu-pn-001), [HU-FAB-001](../42_references/bibliography.md#hu-fab-001).

<a id="valence-band"></a>
**Valence band.** The band containing bonding-related states; its unfilled states can be described as holes.

<a id="conduction-band"></a>
**Conduction band.** An allowed band whose occupied states support conduction electrons.

<a id="band-gap"></a>
**Band gap.** Energy interval between the valence-band maximum and conduction-band minimum.

<a id="electronvolt"></a>
**Electronvolt.** An energy unit equal to the energy change of elementary charge across one volt.

<a id="hole"></a>
**Hole.** A mobile positive-carrier description of a missing valence-band electron; not an empty atomic site.

<a id="intrinsic-semiconductor"></a>
**Intrinsic semiconductor.** An ideal undoped semiconductor with equal equilibrium electron and hole concentrations.

<a id="extrinsic-semiconductor"></a>
**Extrinsic semiconductor.** A semiconductor whose carrier populations are altered by dopants.

<a id="doping"></a>
**Doping.** Deliberate introduction of atoms that alter the semiconductor carrier population; chemical dose and active concentration are different quantities.

<a id="donor"></a>
**Donor.** A dopant capable of supplying a conduction electron.

<a id="acceptor"></a>
**Acceptor.** A dopant capable of accepting an electron and supporting a hole population.

<a id="n-type"></a>
**N-type.** Electrons are the majority mobile carriers; bulk material can still be electrically neutral.

<a id="p-type"></a>
**P-type.** Holes are the majority mobile carriers; bulk material can still be electrically neutral.

<a id="compensation"></a>
**Compensation.** Donors and acceptors offset each other in setting net carrier concentration.

<a id="activation"></a>
**Activation.** Dopants occupy electrically effective configurations, rather than merely being chemically present.

<a id="carrier-concentration"></a>
**Carrier concentration.** Mobile electrons or holes per unit volume, commonly cm⁻³.

<a id="mobility"></a>
**Mobility.** Low-field drift-speed magnitude per electric-field magnitude, commonly cm²/(V·s).

<a id="conductivity"></a>
**Conductivity.** Proportionality between low-field drift current density and electric field in the specified material.

<a id="resistivity"></a>
**Resistivity.** Reciprocal of conductivity; geometry-independent only under specified material and measurement conditions.

<a id="drift"></a>
**Drift.** Average carrier motion driven by an electric field.

<a id="diffusion"></a>
**Diffusion.** Carrier transport associated with a concentration gradient.

<a id="pn-junction"></a>
**PN junction.** A transition between p-type and n-type semiconductor regions.

<a id="depletion-region"></a>
**Depletion region.** A region depleted of majority mobile carriers; fixed ionized dopants contribute space charge.

<a id="built-in-potential"></a>
**Built-in potential.** Equilibrium electrostatic potential difference across a junction; not an available battery voltage.

## MOS and switching

Canonical starting explanation: [From MOS capacitor to transistor: controlling a channel with a field](../06_transistor_fundamentals/mos_capacitor_and_mosfet.md). Related sequence: [Phase 1 reading path](../LEARNING_PATHS.md#phase-1-reading-path). Sources: [HU-MOS-001](../42_references/bibliography.md#hu-mos-001), [HU-MOSFET-001](../42_references/bibliography.md#hu-mosfet-001), [HU-SCALING-001](../42_references/bibliography.md#hu-scaling-001), [MIT-CMOS-001](../42_references/bibliography.md#mit-cmos-001), [MIT-POWER-001](../42_references/bibliography.md#mit-power-001), [IBM-NANOSHEET-001](../42_references/bibliography.md#ibm-nanosheet-001).

<a id="mos"></a>
**MOS.** Metal–oxide–semiconductor structure; the conventional name also applies to varied gate materials.

<a id="mosfet"></a>
**MOSFET.** A transistor whose insulated gate controls a semiconductor channel.

<a id="accumulation"></a>
**Accumulation.** Increased majority-carrier population at the semiconductor surface under gate bias.

<a id="inversion"></a>
**Inversion.** A surface region where the opposite carrier type becomes dominant.

<a id="threshold-voltage"></a>
**Threshold voltage.** A model- or measurement-defined criterion for channel turn-on; not an abrupt zero-current boundary.

<a id="source-and-drain"></a>
**Source and drain.** Terminals that supply and collect channel carriers in the chosen operating condition.

<a id="body"></a>
**Body.** The semiconductor region beneath the channel, a fourth electrical terminal in the basic MOSFET model.

<a id="cmos"></a>
**CMOS.** Complementary use of n-channel and p-channel MOS devices.

<a id="inverter"></a>
**Inverter.** A circuit producing the opposite logic state from its input.

<a id="leakage"></a>
**Leakage.** Current remaining outside the intended strong-conduction path or nominal on-state.

<a id="switching-activity"></a>
**Switching activity.** A defined count or probability of transitions per cycle; its convention must accompany a power formula.

<a id="finfet"></a>
**FinFET.** A transistor with a fin-shaped channel and gate control over exposed top and side surfaces.

<a id="gate-all-around"></a>
**Gate-all-around.** A geometry in which gate control surrounds the channel cross section; abbreviated GAA.

<a id="nanosheet"></a>
**Nanosheet.** A sheet-shaped channel that can be stacked in a GAA arrangement; a form of GAA, not a separate compulsory successor.

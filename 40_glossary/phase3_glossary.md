# Phase 3 terminology

| Term | Meaning | Owner |
|---|---|---|
| Well / active region | Body-doping region / region used for device formation | [Device integration](../17_transistor_fabrication/planar_and_finfet.md) |
| STI | Shallow trench isolation: dielectric-filled trenches between active regions | [Device integration](../17_transistor_fabrication/planar_and_finfet.md) |
| Sidewall spacer | Dielectric beside a gate that establishes separation/protection | [Device integration](../17_transistor_fabrication/planar_and_finfet.md) |
| RMG / gate-last | Replacement metal gate: a temporary gate is replaced during integration | [Device integration](../17_transistor_fabrication/planar_and_finfet.md) |
| High-k / EOT | Higher relative permittivity / equivalent reference-oxide thickness for equal ideal capacitance | [Gate stack](../17_transistor_fabrication/planar_and_finfet.md) |
| Work-function metal | Gate material used to establish the electrostatic boundary condition | [Gate stack](../17_transistor_fabrication/planar_and_finfet.md) |
| GAA / nanosheet | Gate-all-around / thin horizontal channel surrounded by an insulated gate | [Nanosheets](../17_transistor_fabrication/nanosheet_integration.md) |
| Inner spacer / channel release | Dielectric at sheet ends between channels / selective removal that exposes retained sheets | [Nanosheets](../17_transistor_fabrication/nanosheet_integration.md) |
| Stiction | Unwanted adhesion of surfaces that should remain separated | [Nanosheets](../17_transistor_fabrication/nanosheet_integration.md) |
| MOL / contact / silicide | Terminal-access integration / electrical terminal connection / silicon–metal compound | [Contacts](../17_transistor_fabrication/contacts_and_mol.md) |
| Specific contact resistivity | Interface property in Ω·cm²; differs from measured contact resistance in Ω | [Contacts](../17_transistor_fabrication/contacts_and_mol.md) |
| Via / local-global wiring | Connection between levels / routing scopes of different extent | [Wire physics](../18_interconnects/wire_rc.md) |
| RC / Elmore first moment | Resistance–capacitance loading / approximate timing metric, not exact threshold-crossing delay | [Wire physics](../18_interconnects/wire_rc.md) |
| Crosstalk / IR drop | Unwanted coupling between signals / resistive voltage loss | [Wire physics](../18_interconnects/wire_rc.md) |
| Barrier / liner / seed | Diffusion blocking / interface or growth support / preparation for fill | [Materials](../18_interconnects/materials_and_reliability.md) |
| Low-k / SiOCH | Lower relative permittivity / silicon-oxygen-carbon-hydrogen dielectric family | [Materials](../18_interconnects/materials_and_reliability.md) |
| Electromigration / TDDB | Current-associated atomic transport / time-dependent dielectric breakdown | [Reliability](../18_interconnects/materials_and_reliability.md) |
| Damascene / dual damascene | Conductor inlay in a recess / shared trench-and-via fill module | [BEOL](../19_back_end_of_line/beol_integration.md) |
| Subtractive / semi-damascene | Pattern deposited conductor by removal / hybrid integration using direct metal patterning | [BEOL](../19_back_end_of_line/beol_integration.md) |
| Superfill / enclosure | Preferential feature-filling behavior / geometric extension of landing beyond a via | [BEOL](../19_back_end_of_line/beol_integration.md) |
| Passivation / terminal metallurgy | Protective surface stack / metals at an intended external connection interface | [BEOL](../19_back_end_of_line/beol_integration.md) |
